## 2. 关键实现细节

- **等级单向依赖（INV-16）**：`follow_up_grade_of` 只读取已算出的 `lead_class`、风险等级、置信度、`identity.status` 与信号集；A252 用 200 个合成包比较开关等级输入前后的风险分、等级、置信度与核实度，全部相同。
- **枢纽例外**：剔除发生在 `render_card` 计算 `ids` 之后，风险分、`compute_credit`、`CONTACT_CONTRA`、attention 与维度备注都使用同一份 `ids`，所以下游一致；旧包没有 `intake.phone_country` 时不触发（A259/A261）。
- **旧包字节**：A146/A253 仍用 `card_harbor.expected.txt` 全文字节比对；A272/A282 复用同一快照，确认 K-04/K-06 字段只在存在时输出。
- **隐私**：`search_variants` 只在 `phone_check` JSON；卡片与报告不出现完整号码（A278）。
- **K-07 残余风险**：Python 仍未用“已校验 IP”建连（urllib 重新解析 DNS），报告与 `docs/validation.md` 如实记录，未假装已防住。
