# 采集清单（data-sources/collection_checklists.md）

供半自动与纯人工档使用：业务员按清单查看链接，回传要点，Skill 增量复核。**一次只看一页、低频、只读；不登录就跳过并标注「未核实（未登录）」，不扣分。**

## 0. 开始前（LinkedIn 提醒）

浏览个人资料会让对方看到访问记录。开始前先在 LinkedIn「设置 → 个人资料查看选项」调为**私密模式**（入口以平台当前界面为准）。

## 1. WhatsApp 商业资料

| 看什么 | 回传什么 |
| --- | --- |
| 商业资料页：网站、邮箱、地址、行业 | 逐项抄录（没有就写无） |
| 头像 | 反搜结果（Google Lens / TinEye：是否命中另一身份/图库） |
| 简介 | 原文 |
| 号码区号 | 已由 phone_check 自动判定，无需回传 |

## 2. Facebook 主页与页面透明度

| 看什么 | 回传什么 |
| --- | --- |
| 页面创建时间（页面透明度/About） | 创建日期 |
| 管理员所在国家 | 国家列表 |
| 是否商业主页、内容与活跃度 | 一句话描述 |
| 头像/封面图 | 反搜结果 |

## 3. LinkedIn 主页

| 看什么 | 回传什么 |
| --- | --- |
| 任职公司与职位（与自称比对） | 摘要原文 |
| 公司页与官网是否互相指向 | 两个链接 |
| 账号活跃度（动态/人脉） | 一句话描述 |

## 4. 地图（Google Maps / 高德）

| 看什么 | 回传什么 |
| --- | --- |
| 地址是否存在、是什么类型（工厂/写字楼/住宅/空地/共享办公） | 街景所见一句话 |
| 招牌与公司名是否一致 | 是/否 |
| 商家公示电话与网站 | 电话与链接（与询盘比对） |
| 评论与照片 | 是否疑似刷评（一句话） |

局限：有商家页 ≠ 可信，评论和照片可刷。

## 5. 海关（仅限有免费公司级数据的国家）

| 看什么 | 回传什么 |
| --- | --- |
| 品类（HS 编码/产品描述 vs 询盘品类） | 品类摘要 |
| 角色（制造商出口多/贸易商/采购商以进口为主） | 角色一句话 |
| 规模（历史单票金额与频次 vs 询盘订单量） | 大致量级 |
| 官网在售产品 vs 海关品类 | 是否吻合 |

局限：没记录 ≠ 有问题；覆盖不均；无免费公司级数据的国家直接跳过、标注 not-covered、不扣分。
## 6. 三层核实采集（v0.8.0）

| 层 | 看什么 | 回传什么 |
| --- | --- | --- |
| 公司层：官方社媒互指 | 官网页脚/联系页指向的 Facebook/LinkedIn/Instagram/YouTube；该页简介或网站字段是否回指官网 | 两个链接 + 是否互指（强/名称匹配） |
| 公司层：LinkedIn 公司页 | 官网是否互指、行业、员工规模与官网自称是否相近 | 链接 + 行业/规模摘要 |
| 链接层：员工姓名/照片 | 官网团队/联系页、官方 Facebook 帖子/照片、LinkedIn 个人页 | 只回传买家一人：姓名/职位/照片是否对得上、来源链接 |
| 人物层：头像 | 各平台头像是否同图/近似图；Google Lens/TinEye 是否命中另一身份 | 同图/近似图/不同/无法比对 + 反搜结果 |
| 人物层：账号时长/厚度 | 页面创建时间、管理员国家、加入时间（仅公开可见）；最早/最近内容、照片场景、评论/标记、原创度 | 活动跨度、厚度（厚实/一般/单薄）、是否近期改名/改公司/改头像 |

**边界**：不登录就跳过并标「未核实（未登录）」；不枚举公司其他员工；不保存头像；不做人脸识别。

## 7. 地图规模（名称/地址/电话对上后）

| 看什么 | 回传什么 |
| --- | --- |
| 建筑类型与体量 | 层数/占地/外观（工厂、店面、写字楼单间、民房） |
| 周边环境 | 工业区 / 商务区 / 居民区 |
| 招牌与门牌 | 是否有公司名 |
| 同址公司 | 是否共享办公/虚拟地址 |
| 商家页信息 | 照片、评价数量、营业时间 |
| 街景日期 | 街景左下角的拍摄年月 |

判断：吻合 / 偏小 / 住宅型 / 无法判断。只有「自称工厂/大公司/大订单」与「所见小/住宅型」同时成立才计分；贸易商/小公司/单独住宅型不计分。
